# PRD

## 1. 제품 약속

PLANLOG는 사용자의 감성, 여행 타입, 도착 시간, 이동 방식만으로 강원도 하루 여행 코스를 자동 생성하고, 실제 방문 경험을 스탬프와 감정 기록으로 남기는 반응형 웹 서비스다.

핵심 약속은 세 가지다.

1. 검색보다 선택: 목적지를 직접 고르지 않아도 감성과 조건만으로 코스를 만든다.
2. 계획보다 실행: 여행 당일 길찾기, 스탬프 획득, 기록 저장까지 한 흐름으로 연결한다.
3. 저장보다 축적: 방문 경험이 기록 카드와 감성 지도에 누적된다.

## 2. 왜 만드는가

- 혼자 떠나는 강원도 여행은 정보 탐색 비용이 높고, 당일 실행 흐름이 끊기기 쉽다.
- 기존 여행 서비스는 장소 탐색과 숙소 검색에는 강하지만 감성 기반 하루 코스 자동 구성과 방문 기록 누적 경험은 약하다.
- 공모전 심사자와 일반 사용자 모두가 짧은 시간 안에 서비스 가치를 이해해야 하므로 반응형 웹 기반의 명확한 데모 경험이 필요하다.

## 3. 대상 사용자

- 혼자 강원도 여행을 준비하는 20~30대 사용자
- 여행 기록을 간단히 남기고 싶은 사용자
- 공모전 심사자 및 데모 체험 사용자

## 4. 범위

### In Scope

1. 반응형 웹 랜딩과 핵심 소개
2. 4단계 무드 셀렉터
3. 코스 로딩과 코스 결과
4. 코스 상세, 장소 상세, 장소 변경
5. 숙소 추천 및 직접 입력
6. 저장한 코스, 나의 기록, 기록 카드 상세, 마이페이지
7. 2km 반경 기반 스탬프 상태 UI
8. 심사자 체험 모드

### Out of Scope

1. 네이티브 앱 기능
2. 실시간 채팅, 여행 메이트 매칭, 커뮤니티
3. AI 챗봇 기반 자유 대화형 코스 생성
4. 숙소 상세 페이지와 숙소 전체 검색 페이지
5. 다국어 전체 지원

## 5. 기능 요구사항

### Must Have

1. GNB: `PLANLOG | 코스 만들기 | 추천 코스 | 나의 기록 | 로그인`
2. 비로그인 상태 보호 진입 시 로그인 모달 노출
3. 카카오/Google 로그인 CTA
4. 랜딩 Hero, 축제, 코스 생성 방식, 감성 지도 프리뷰
5. 무드 셀렉터 4단계
6. Google Calendar 유사 날짜/시간 선택 UI
7. 시작 지점 유형별 분기 입력
8. 코스 자동 생성 로딩 상태와 데이터 활용 문구
9. 지도 + 일정표 기반 코스 결과
10. 추천 이유 카드
11. 숙소 선택 또는 직접 입력 후 일정 반영
12. 장소 상세의 스탬프 5상태 UI
13. 모바일 Active Trip / Stamp Complete 화면
14. 저장한 코스, 감성 지도, 여행 성향, 기록 카드, 마이페이지

### Should Have

1. 같은 코스를 걷는 사람들의 감정 리스트
2. 존별 저장 코스 보기
3. D-Day 알림, 코스 리마인드 토글
4. 심사자 데모 상태 전환

### Could Have

1. 재추천 옵션
2. 공유 고도화
3. 감성 성향 상세 분석

## 6. 비기능 요구사항

- Desktop과 Mobile에서 모두 읽히는 반응형 UI
- 더미 데이터만으로도 심사 흐름을 재현할 수 있어야 함
- 이후 API 연동을 고려한 상태 관리와 데이터 계층 분리
- 위치 권한, 로그인, 저장 기능은 실제 운영 전까지 명확한 가드 필요

## 7. 우선순위

1. 코스 생성 플로우
2. 코스 결과/상세/장소 상세
3. 스탬프 및 기록 저장 흐름
4. 저장한 코스/나의 기록/마이페이지
5. 심사자 데모와 보조 기능

## 8. 검증 기준

### 제품 검증

- 사용자가 첫 화면에서 10초 안에 서비스 목적을 이해할 수 있는가
- 사용자가 4단계 입력만으로 코스 결과에 도달할 수 있는가
- 심사자가 위치 인증 없이 스탬프 경험을 확인할 수 있는가
- 사용자가 저장, 기록, 회고 흐름을 화면 간 이동으로 이해할 수 있는가

### 구현 검증

- 주요 라우트가 모두 존재하는가
- 입력 상태가 폼 검증으로 관리되는가
- 서버 상태와 클라이언트 상태 책임이 분리되어 있는가
- `.env`와 `.gitignore`가 비밀값 유출을 막고 있는가
